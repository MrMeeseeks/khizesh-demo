# خیزش — قیام شیر (دموی رایگان) · KHIZESH: Rise of the Lion — Free Demo

A pixel-art beat 'em up about the torch of Iran's protest movements, passed from hand to hand.
This free demo includes the tutorial, the prologue (Tehran University dorms, July 1999) and chapter 1 (Rasht).

Play in the browser: open `index.html`.
